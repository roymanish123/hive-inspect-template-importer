# Product research and remaining validation

This is documentation-based research conducted on 9 November 2026. It is not a claim of hands-on trial usage.

Spectora's official export instructions distinguish HTML-text from plain-text exports. Its spreadsheet guide lists section/item/comment fields and source settings, and describes the within-item order column. This informed a deterministic importer with explicit column mapping and order handling. The published blank layout contains column definitions rather than genuine inspection narratives.

Sources: [export instructions](https://support.spectora.com/en/articles/2769896-how-to-export-a-template), [spreadsheet schema](https://support.spectora.com/en/articles/6198400-how-to-import-a-template-from-a-spreadsheet), [published blank layout](https://docs.google.com/spreadsheets/d/1gdMsUItVACbL4fq1Pqiie_u3xk_5UeMjPQTvhh1sMRU/edit).

Hive's official documentation index describes template upload, an editable hierarchy, duplication and explicit saving. It also describes some cross-template operations as writing immediately. Based on that documentation, an explicit save state and a way to inspect migration coverage are useful design hypotheses. These are not verified findings of defects in Hive. The app therefore shows unsaved changes, saved revisions, original source evidence and row reconciliation.

Source: [Hive official documentation index](https://docs.hiveinspect.com/llms.txt), template import, structure and editing entries. Direct article retrieval failed during this research.

Required hands-on follow-through: use a shareable sample in Hive; complete and publish a sample inspection; try template upload; use Spectora to select and export an actual HTML-text template; record concrete observations and validate the exported file. No specific usability criticism or Binsr comparison should be presented as firsthand experience until those actions are completed.
